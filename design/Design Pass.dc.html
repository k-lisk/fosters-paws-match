Per-card donate, removed: the icon/pill that sat on each dog's photo is gone. Legally, money given on a specific dog's card reads as earmarked for that dog's care — a general "support the rescue" ask can't live there. Donate now only appears as the one full-width button below, which gives to the general fund.

Learn More stays outline (secondary); both cards' Learn More buttons are pinned to the bottom regardless of bio length.

Tag limit, mocked up: Pepper's card shows what happens past the cap — 4 tags display, a 5th+ collapses into a single "+N more" pill rather than wrapping to a third line or crowding the card. Willow's card shows the normal 3-tag case for comparison. Recommend capping at 4 visible tags per card app-wide.

Donate call, resolved: a full-width "Donate to the rescue" button is on both results screens' CTA stack (general fund only, per the legal note above) — not gated behind a per-dog icon. Most people who take either flow, especially the quiz, aren't going to adopt but plenty want to support the rescue; hiding the ask behind a small icon shut out that majority. It sits below the primary action so it never competes with the flow's main task.

3 & 4 & 5 — Component Sheet

Button hierarchy, icon set, grid rules

CTA color hierarchy

Primary — solid accent
One per screen. The main flow action: Continue, Find My Match.
Secondary — accent outline
Supporting actions: Learn More, View Puppies/Adult Dogs.
Tertiary — text only
Low-commitment utility: Start Over, Retake Quiz, Back.
Donate — solid neutral-dark
Deliberately distinct from the brand accent so it reads as its own serious ask. Only ever a general-fund ask — never attached to a specific dog's card.

Icon system

One line-icon vocabulary — 1.8–2.2px stroke, rounded joins, accent color — replacing every emoji in both flows. Audited against every question in GuidedMatch.jsx and SpiritDogQuiz.jsx; mapped explicitly below so nothing ships with a gap.
